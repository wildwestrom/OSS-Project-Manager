# Contributing

Contributions are welcome — bug fixes, features, documentation improvements, whatever you have.

## Reporting Issues

Open a GitHub issue with a clear title and description. Include steps to reproduce if it's a bug.

## Submitting Changes

1. Fork the repository and create a branch from `main`.
2. Make your changes.
3. Open a pull request with a short description of what you changed and why.

## Code Style

- Follow [PEP 8](https://peps.python.org/pep-0008/).
- Keep functions small and focused.
- No unnecessary dependencies.

## Ground Rules

- Don't be an idiot.
- Be respectful in all project spaces.
- Keep pull requests focused — one change per PR.
