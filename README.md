# Open Source Project Manager

Manages an open source project

## Usage

Steps:  
1. Install Python 3.13 on your machine.
2. Clone the project with `git clone`.
3. Open the project folder.
3. Install the `semver` package: `pip install semver`
4. Run this command in a terminal.
```shell
python main.py
```

No additional packages are necessary. We only use the standard library.

If you get an error that `python` was not found, put it in your `PATH` environment variable. If you don't know what that means or how to do it, go google it.

If you don't know what a terminal is. Go google it.

If you don't know what Python is, why are you here?

The program comes with instructions built in once you run it. For details about the code itself see the [architecture docs](./docs/Architecture.md).
